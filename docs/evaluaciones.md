# Evaluaciones académicas

Este archivo explica cómo funciona el sistema de evaluaciones en EduCampus LMS.

## Tipos de evaluación

La plataforma maneja dos tipos de evaluación:

### Evaluación numérica

Se le asigna una nota entre 0.0 y 5.0 al estudiante según su desempeño.
Es el tipo más común en la mayoría de instituciones.

### Evaluación por logros

En vez de una nota, se determina si el estudiante alcanzó el objetivo o no.
Los resultados posibles son: Logrado, En proceso o No logrado.

## Escalas de desempeño

| Rango     | Nivel de desempeño |
|-----------|--------------------|
| 4.6 - 5.0 | Superior           |
| 4.0 - 4.5 | Alto               |
| 3.0 - 3.9 | Básico             |
| 0.0 - 2.9 | Bajo               |

## Registro de notas

El docente ingresa las notas por actividad dentro de cada módulo del curso.
Se pueden editar hasta que el periodo académico sea cerrado.

## Resultados por periodo

Al terminar el periodo, el sistema genera un resumen con las notas finales
de cada estudiante, el promedio general y las materias aprobadas o reprobadas.
