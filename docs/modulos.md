# Módulos de EduCampus LMS

Acá se describen los módulos principales que tiene la plataforma.

## Módulo de usuarios

Permite registrar y gestionar a las personas que usan el sistema.
Hay tres tipos de usuario: administrador, docente y estudiante.
Cada uno tiene permisos distintos dentro de la plataforma.

## Módulo de cursos

Desde este módulo se crean y gestionan los cursos del sistema.
Los docentes pueden agregar contenido, unidades y recursos para sus clases.

## Módulo de inscripciones

Acá los estudiantes se matriculan en los cursos disponibles.
El sistema valida si el estudiante cumple los requisitos antes de inscribirlo.

## Módulo de evaluaciones

Permite crear quices, parciales y trabajos.
El docente puede configurar fechas, número de intentos y el valor de cada actividad.

## Módulo de calificaciones

Registra las notas de cada estudiante por actividad.
Al final del periodo calcula el promedio automáticamente.

## Módulo de reportes académicos

Genera informes del rendimiento de los estudiantes.
Muestra datos como porcentaje de aprobación, notas por materia y progreso general.
